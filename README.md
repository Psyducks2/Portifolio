# ⚡ Portfólio Profissional — Luis Roberto

Portfólio moderno de alto impacto visual e interatividade, desenvolvido em **React**, **Vite** e **CSS Moderno**.

🌐 **Demonstração:** [https://portifolio-three-pi-11.vercel.app](https://portifolio-three-pi-11.vercel.app)

---

## ✨ Funcionalidades & Destaques

- 🎨 **Design Glassmorphic & Cyberpunk/Clean UI**: Suporte a **Tema Escuro & Tema Claro** com transições suaves e design tokens refinados.
- 💻 **Terminal CLI Interativo**: Console de desenvolvedor acessível via botão no cabeçalho ou atalho de teclado (`T`), com comandos interativos (`about`, `skills`, `projects`, `certs`, `contact`, `quiz`, `matrix`, `clear`).
- ⚡ **Matrix Rain Easter Egg**: Modo de chuva digital em Canvas ativável pelo terminal, cabeçalho ou Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`).
- 🧠 **Diagnóstico de Stack (Quiz)**: Teste interativo de 3 etapas que analisa os requisitos do projeto do visitante e sugere a stack recomendada com celebração de confetes (`canvas-confetti`).
- 🏆 **Jornada Gamificada do Visitante**: Widget que acompanha o progresso de exploração do visitante na página e desbloqueia o download do currículo oficial em PDF ao atingir 100%.
- 📜 **Seção de Certificações & Formação**: Destaque para graduação em ADS @ FAMETRO e certificações internacionais (Microsoft Azure AI-900, Cisco Cybersecurity, AWS na Prática, Testes de Software & QA, Power BI, Infosec).
- 🚀 **Projetos em Destaque**: Filtros dinâmicos por categoria (Web Full Stack, Mobile Android, IoT & Inovação, Sistemas & Lua, Bots & Ferramentas) com cards ricos (BioTrack, ORYN, PsyAntiCheat-REDM, Mover, Base Andromeda, Calculadora Penal, Aura Apresentações, ArrowNotfys).
- 📊 **Estatísticas & Snake Graph do GitHub**: Integração com GitHub Streak, cards de estatísticas, top linguagens e visualizador da animação do Snake.
- 📱 **Botão Flutuante do WhatsApp**: CTA direto com notificação inteligente para abertura de canal de comunicação rápido.
- 🌐 **Internacionalização (i18n)**: Suporte completo a **Português (PT-BR)** e **Inglês (EN)**.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: React 18, Vite
- **Ícones & Efeitos**: Canvas Confetti, Lucide React
- **Estilização**: CSS Moderno (CSS Variables, Flexbox, CSS Grid, Glassmorphism, Spotlight Card Cursor Glow)
- **Internacionalização**: React Context API & Custom i18n Dictionary

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Psyducks2/Portifolio.git
   cd Portifolio
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gere a build de produção:**
   ```bash
   npm run build
   ```
